# 第4章 初步探索性数据分析(EDA)

本章沿着“载入数据 → 概览数据集 → 划分特征类型 → 分离特征与标签”的顺序，演示开始建模前的基本数据认识工作。各小节脚本可独立阅读；需要实际运行时，应先准备相应数据文件或数据获取环境。

## 子章节与配套代码

| 书稿小节 | 代码文件 | 用途 |
| --- | --- | --- |
| 4.0 EDA 的概述 |  | 理解探索性数据分析的任务与顺序。先阅读书稿，建立整体流程。 |
| 4.1.1 载入数据概述 |  | 认识输入数据格式与读取方式。按格式阅读 4.1.2 的示例函数。 |
| 4.1.2 载入数据代码实战 | [4.1、载入数据/4.1.2_load_file_formats.py](4.1、载入数据/4.1.2_load_file_formats.py) | 对照 TXT、CSV、XLSX、JSON、XML、Parquet 和 HDF5 的读取方法。传入仓库内数据文件的相对路径；HDF5 可用 `--dataset` 指定原生数据集名称或 pandas 键；随书 `五、数据工程(数据分析+数据处理)/titanic_df.h5` 属于 pandas HDFStore，使用默认键 `data`。 |
| 4.2.1 初步概览数据集信息概述 |  | 认识字段、缺失情况和特征分布。先阅读书稿，再查看 EDA 报告示例。 |
| 4.2.2 初步概览数据集信息代码实战 | [4.2、初步概览数据集信息/4.2.2_profile_dataset.py](4.2、初步概览数据集信息/4.2.2_profile_dataset.py) | 为 Titanic 数据生成概览报告。运行后用浏览器查看本节生成的 HTML 报告。 |

## 建议阅读顺序

依次阅读 4.1 的文件载入、4.2 的数据概览、4.3 的特征类型识别，以及 4.4 的特征与标签拆分。

## 注意事项

从仓库根目录运行脚本，环境信息参见 [conda-spec-win64.txt](../conda-spec-win64.txt)。4.2.2—4.4.2 的部分示例读取 OpenML Titanic 数据，首次获取可能需要网络。4.1.2 需要自行指定要读取的仓库内文件；4.4.2 的 T3 使用现有 `五、数据工程(数据分析+数据处理)/titanic_df.csv`。
