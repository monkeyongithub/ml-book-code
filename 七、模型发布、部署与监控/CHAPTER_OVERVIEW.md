# 第7章 模型发布、部署与监控

本章沿着“发布 → 部署 → 监控”的顺序，说明如何比较候选模型、提供预测接口，以及观察数据分布和训练过程。代码是与书稿小节配套的教学示例；A/B 数据、Profiler 输入均为模拟数据。

## 建议阅读顺序

先看 7.2 的发布对比，再看 7.3 的预测服务与请求，最后看 7.4 的分布变化和训练监控。

## 注意事项

从仓库根目录运行脚本，所需软件版本参见 [conda-spec-win64.txt](../conda-spec-win64.txt)。该文件是 Windows 平台的 Conda 环境导出清单，不是 pip 的 -r 格式；在其他系统上应准备相应的兼容环境。

7.3.4 与 7.4.3 的 TensorBoard 示例使用 OpenML 的 Titanic 数据；首次获取数据可能需要网络。7.3.4 的服务仅监听本机 127.0.0.1:5000，两个请求脚本应在服务启动后运行。T2 的日志保存在仓库内本章 7.4、模型监控/logs；需要查看时，可从仓库根目录执行：

~~~bash
tensorboard --logdir=七、模型发布、部署与监控/7.4、模型监控/logs
~~~
