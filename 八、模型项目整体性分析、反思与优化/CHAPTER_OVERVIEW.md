## 建议阅读顺序

先通过 8.2 对照拟合状态与正则化，再阅读 8.3 数据层、8.4 算法层、8.5 系统层和 8.6 代码层的优化内容。

## 注意事项

从仓库根目录按表格顺序阅读或运行选定脚本。使用 `shared.dataset` 的示例可在 macOS/Linux 终端设置 `PYTHONPATH=.`；Windows 终端需使用对应的环境变量设置方式。环境清单见 [conda-spec-win64.txt](../conda-spec-win64.txt)，该文件是 Windows Conda 导出清单，不是 pip 的 `-r` 格式。

8.2.3 的 T2 与 8.4.2 使用 OpenML 的 Titanic 数据；8.3.2 的 MNIST 首次加载也可能下载数据。8.3.5 的 T1 会在 `8.3、数据层面优化/` 目录生成 `data.parquet`，可在观察结果后删除。计时和内存对比是教学示意，不保证固定提升幅度。
