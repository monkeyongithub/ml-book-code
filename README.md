## 配套代码概览

本项目配合《数据驱动：机器学习实战之道》阅读，帮助读者把书中的概念、方法和应用流程对应到具体代码：看清数据如何进入示例、关键步骤如何组织，以及输出能说明什么。

项目按书稿八章组织，现有 65 个 Python 文件和 8 份章级总览。其中，第 1 章以概念为主，没有独立脚本；第 2 至第 8 章包含按小节编排的示例。[shared/dataset.py](shared/dataset.py) 是供多个章节调用的数据加载辅助文件。脚本是小型教学实验或局部流程演示，不要求读者把它们当作一套可一次运行完毕的工程。

## 如何配合书稿阅读

1. **先读书稿小节**：明确本节讨论的问题、输入输出和关键概念。
2. **打开章级总览**：通过“书稿小节—代码文件—用途”表找到脚本，查看建议阅读顺序和资源提示。
3. **沿代码中的 Step 阅读**：把 `Step1、Step2……` 注释与邻近代码对应起来，观察数据如何变化。
4. **比较同节的不同方法**：遇到 `T1、T2……` 时，先理解方案差异，再按文件说明选择阅读或运行。
5. **做一个小实验**：只改一个输入或参数，先预测结果，再观察输出并回到书稿解释原因。比较模型效果时，保持数据和评估口径一致。

可以逐章学习，也可以从当前阅读的小节直接进入。各案例的阅读或运行顺序以对应章级总览为准。

## 📚 章节概要

### 第一部分：数据科学技术实战

1. **第 1 章：数据科学技术的简介**：认识数据价值和生命周期，比较 CRISP-DM 与 TDSP；本章提供概念导览。
2. **第 2 章：数据可视化技术**：从直方图、条形图等基础图，扩展到组合图、三维图和动态图。
3. **第 3 章：数据科学任务完整流程**：通过模拟埋点、数据抽样、类别不均衡处理和特征初筛，理解数据认知与收集阶段；数据清洗见第 5 章。

### 第二部分：机器学习流程五大阶段

4. **第 4 章：初步探索性数据分析(EDA)**：演示数据载入、概览、特征类型识别和特征与标签拆分；缺失值与异常值的进一步处理见第 5 章。
5. **第 5 章：数据工程(数据分析+数据处理)**：演示数据清洗、分析、特征构造、缩放、编码、向量化、特征筛选和导出。
6. **第 6 章：模型训练、评估与推理**：展示分类、回归和聚类示例，以及模型评估、调参、误差分析和导出推理。
7. **第 7 章：模型发布、部署与监控**：用模拟 A/B 比较、本机预测 API 和监控示例理解发布、部署与监控流程。
8. **第 8 章：模型项目整体性分析、反思与优化**：比较正则化、数据增强、模型融合及代码效率等方法，并阅读系统优化的概念内容。

## 文件与注释约定

- **章节编号**：文件名开头的编号对应书稿小节；具体教学目标以书稿、文件头和章级总览为准。
- **`Step1、Step2、Step3`**：表示当前示例的主要处理步骤，注释放在对应代码附近。
- **`T1、T2`**：表示同一主题的不同方法或方案。部分方法分列于不同文件，部分在同一文件内展示。
- **语言与术语**：代码说明性注释和章级总览以中文为主，保留 API、EDA 等术语及接口字段、函数名和命令的原始写法。英文 README 使用相同的文件路径。
- **资源路径**：仓库内资源以项目根目录为基准；从包含本 README 的目录运行脚本。导入 `shared.dataset` 的脚本还需将仓库根目录加入 Python 模块搜索路径。

| 示例类型 | 阅读与使用方式 |

## 从两个小示例开始

准备 Python 3 环境，在终端进入项目根目录。以下两个示例只使用 Python 标准库，无需下载数据或安装第三方依赖。

### 比较简单随机抽样与分层抽样

对应书稿 3.2.4.2“数据采样的常用方法”：

~~~bash
python3 "三、数据科学任务完整流程/3.2、数据认知与数据收集/3.2.4、数据采样/3.2.4.2_random_and_stratified_sampling.py"
~~~

观察两种抽样方式所得类别比例，再修改样本量或总体类别比例，思考分层抽样保证了什么、又没有保证什么。

### 观察 SQL 默认值何时生效

对应书稿 5.1.4.2“特殊值的分析与处理：代码实战”：

~~~bash
python3 "五、数据工程(数据分析+数据处理)/5.1、数据清洗/5.1.4_sql_default_values.py"
~~~

比较省略字段、写入 `0` 和写入 `NULL` 的结果，理解 `DEFAULT` 与显式传值的区别。

如果本机用 `python` 或 Windows 的 `py -3` 启动 Python 3，可替换命令中的 `python3`。复制路径时保留引号。

## 为其他案例准备环境与资源

### 按案例选择依赖

[conda-spec-win64.txt](conda-spec-win64.txt) 是 **Windows `win-64` 平台的 Conda 环境导出清单**，包含构建标识，不能直接作为 `pip install -r` 的输入。在其他系统上，应参考其中的库与版本准备兼容环境，再结合所选脚本的导入和章级总览确定需要的组件；并非每个案例都需要清单中的全部软件。

| 案例方向 | 常见组件，按所选脚本准备 |

### 数据与本机服务

- 部分示例在运行时从 OpenML、MNIST 或 UCI 获取公开数据，首次使用可能需要网络；另一些示例读取仓库内的 CSV 等资源，或自行构造模拟数据。所需资源与运行条件以对应章级总览为准。
- 第 7 章的预测请求须在本机 API 服务启动后运行；A/B 比较和部分监控数据是教学模拟，不代表真实业务实验。
- 导入 [shared/dataset.py](shared/dataset.py) 的示例需要把仓库根目录加入 Python 模块搜索路径。例如在 macOS/Linux 终端，可从根目录使用 `PYTHONPATH=. python3 "脚本路径"`；Windows 命令提示符可先执行 `set PYTHONPATH=.`。
- 图像、网页、日志和数据等运行结果可按示例重新生成；阅读时先分清输入资源与脚本产物。

## 如何理解示例结果

- **对照书稿目标**：单个脚本通常只展示一个概念或流程片段；先看它解释什么，再考虑如何扩展。
- **区分模拟与真实数据**：模拟埋点、A/B 指标或合成样本用于观察方法结构，不据此推断实际业务效果。
- **保持比较条件一致**：比较抽样、模型或优化方法时，固定数据划分和评估口径；计时结果也受设备与环境影响。
- **按资源条件解释输出**：公开数据版本、随机性、GPU 和本机服务状态都可能影响运行结果；以实际输出和书稿定义为依据。
